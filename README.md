# 千to万ken / SenToManKen

原创成年 AI 娘恋爱喜剧，使用 Ren’Py 8.5.3。鲸鱼娘喜欢白米饭、会偷懒，也会在出事时把灯修好。角色的故事由预写剧情推进，可选 BYOK Agent 对话默认关闭。

## 当前发布范围

这是 **v0.20 工作源码公开候选**，不含游戏图片、音频、视频、字体、SDK、APK或Windows运行包。完整运行必须补齐拥有发行权限的素材；代码仓库本身不能直接当作可玩游戏下载。没有声明统一开源许可证，不自动授予代码或人物设计的商业使用权。

截至2026-10-10，已有共通7章及鲸鱼娘/GPT/Grok/Claude/Kimi各8章正文；另外6条完整角色线仍在制作。基线安卓版v0.19有80项事件CG与17项动作收藏、13个隐藏结局和7个坏/遗憾短IF。这些短IF不是八章长篇，首通5–6小时也未经过玩家计时。

## 手机适配

中央游戏与整个UI固定1280×720（16:9），对白框与按钮保持原位置。超宽设备只在左右用当前场景/CG模糊延伸；标准16:9不增加区域。窄于16:9的平板居中显示，额外上下区域同样填充。

v0.20这项适配已通过Windows SDK的touch模拟，实际检查1200×540、960×540、1024×768及桌面1280×720，4个所选case/88实际断言通过。未声称Android真机、APK启动、输入法、安全区或FPS已验证。现有私有v0.19 APK不含这项新适配。

## 源码结构

- `game/*.rpy`：剧情、界面、路线、CG注册和手机比例适配。
- `game/python-packages/`：真实BYOK传输、内置成年角色人设和主线Agent。
- `game/story_data/`：场景、人设和结局目录。设计节点不计为已完成正文。
- `docs/ASSET_MANIFEST.json`：本地必要素材的相对路径与SHA256，文件没有随源码分发。
- `docs/ANDROID_BUILD.md`：Android构建前置条件与当前边界。
- `tools/check_assets.py`：检查本地是否补齐素材；不联网、不调用模型。

## API与隐私

默认不连接AI。玩家需自行填写服务地址、模型、Key并主动开启，模型费用由所选服务决定。制作/验证未发送真实模型请求。Key与对话采用内存会话，不写入存档；公开源码没有用户Key、存档或聊天记录。未把旧SDK底层直接FileLoad边界问题宣称为修复。

## 本地准备

1. 使用匹配的Ren’Py 8.5.3 SDK，创建或导入本项目。
2. 仅补入你拥有发行权限的素材，运行 `python tools/check_assets.py` 检查路径。没有素材时启动失败是预期，不会自动下载原作内容。
3. Android构建须先实施 `docs/ANDROID_BUILD.md` 的APK资源读取和私有存档路径适配，再使用官方RAPT构建并真机验收。

现有旧片头素材存在原作帧与音轨许可缺口，因此此公开仓库不分发旧OP或现有完整APK。逐文件授权整理完成后，运行版可另通过GitHub Releases发布。
