# 素材许可与发布范围

本仓库除一张项目主页宣传PNG外，未包含运行美术、音视频、字体或APK。素材manifest只记录游戏资源的相对路径与SHA，不授予任何许可。宣传图的来源、改动与共享条件另见 [POSTER_CREDITS.md](POSTER_CREDITS.md)。

AI娘人物设计有关联CC BY-NC-SA4.0来源，存在按具体文件非商业发布的路径；须逐文件确认设计链、署名与相同方式共享要求，不能将重新生成理解为消除原设计限制。此次只展示一张带相关衍生形象的非商业项目主页海报，不分发角色图包或运行资源。不能从这一张图的说明推断其他资产已获得完整发行许可。

六首黑耀耀和四首Kevin MacLeod曲目有逐文件CC BY4.0许可及署名；Source Han字体有OFL许可。实际发布相应媒体时必须保留许可和署名。

旧OP含34张参考片头帧。实际本地APK中的02制作标识帧与《千恋万花》原片截图SHA一致，来源说明为保留原图；旧festival.ogg/片头视频也未找到可覆盖转载的许可依据。它们未随公开候选分发。此结论不同于“非商业就不能公开所有新图”。

原作公开页面仅作视觉研究；不以原作标识或素材作为本项目的公开发行物。不表示与模型公司、角色原设计作者或原游戏公司有官方关联。

代码公开不等于声明开源协议。本项目尚未选择代码许可证；人物、第三方音轨、字体须各自核许可，不能套用统一MIT覆盖。
