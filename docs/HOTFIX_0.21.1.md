感谢 [chenyichen0420](https://github.com/chenyichen0420) 在 [PR #3](https://github.com/870255475-del/sen-to-man-ken/pull/3) 和 [PR #4](https://github.com/870255475-del/sen-to-man-ken/pull/4) 提供的排查与修复建议。两份 PR 经过审查后调整采用，没有原样合并：

## 3. 更新后的体验与保留内容

鉴赏页面可显示新增 CG 的名称及正确分类，保留原图、解锁条件、全屏与差分切换。GPT/Grok 路线完成章节后，按所选角色继续处理下一章、好感与结局。

现有剧情、泳池番外、CG 动态效果、手机 16:9 排版与宽屏两侧填充保持。212 项媒体与 v0.21 字节一致，本次未降低画质、增加权限或调用真实 AI 接口；BYOK 仍默认关闭。本次未更新 Windows 安装包或重新部署 Toy 网页版。
