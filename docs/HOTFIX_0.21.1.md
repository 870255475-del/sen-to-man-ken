# Android v0.21.1 修复说明（2026-10-24）

本次针对玩家反馈的 CG 鉴赏与 GPT/Grok 个人线崩溃。感谢 [chenyichen0420](https://github.com/chenyichen0420) 在 [PR #3](https://github.com/870255475-del/sen-to-man-ken/pull/3) 和 [PR #4](https://github.com/870255475-del/sen-to-man-ken/pull/4) 提供排查与修复建议；两个 PR 经审查后按实际发行源调整，没有原样合并。

## CG 鉴赏

原版从主菜单进入已解锁的新增 CG 时，本地引擎实际复现 `KeyError: v20_c01_safe_connect`。修复短标题缺失时的回退，并补齐 v20 共通和鲸鱼娘的角色映射。104 个图库条目的标题、分组、资源路径及差分引用已逐项检查；公开主菜单和局内入口、收藏/未收藏、全屏、角色筛选、动态开关和差分切换有实际回归记录。

未采用 PR #3 中再次注册 safe_connect 的部分：它已在 scene_art_v20 中注册，重复添加会产生重复条目。原图、原标题和解锁条件保留。

## GPT/Grok 章节衔接

章节开始时通过普通函数取得路线；子章节返回、后续章节和关系结局使用已存在于存档中的 side_route 身份，避免继续依赖可能丢失的临时 role 参数。不新增只在入口初始化的 side_role，避免旧档中途恢复时缺少新变量。

玩家报告的 Android 自然触发条件未在本地 SDK 重现。已直接提取官方旧 APK 的编译脚本验证公开入口；另外用明确的参数丢失夹具复现同位置 NameError，修后通过。GPT/Grok 公开章节推进、共通邀请、友人/等待结局及状态隔离均有回归；这不是安卓真机全剧情通关证明。
